Help

Run A Service

Open Library, add hymns to the Service Queue, choose the audio output, select the first hymn, then press Play. The next hymn waits until you choose it.

Sound Output

Use This Device for phone, tablet, or laptop speakers. Use Sound System when the Raspberry Pi is connected to the church audio system.

How It Connects

Phones, tablets, and laptops open Hymn Console over the church network. The Raspberry Pi stores the hymns, serves the app, and sends Sound System or AirPlay audio to the church mixer or speakers.

AirPlay From iPhone

The installer enables an AirPlay receiver named from the app name plus AirPlay. On iPhone, open Control Center, tap the audio output icon, and select Hymn Console AirPlay or your custom app name followed by AirPlay. Reboot the Pi after audio or firewall changes if AirPlay connects but does not play sound.

Queue Controls

Use the arrows to reorder hymns. Use verse count and Intro, Verses, Chorus checkboxes to shape what plays. On iPhone, the queue uses a compact touch layout.

Plans

Use Plans to load a saved order of service. Use Save on the Service page to name and store the current queue.

Library And Editing

Use search, hymn theme search, or the alphabet bar to find hymns. Select a hymn from the Library to edit page number, key, tempo, themes, notes, audio defaults, and song structure.

Smart Build

Smart Build estimates intro, verse, and chorus timing. Review and adjust segment times before relying on it for a service.

Assistant Tools

In Library Management, use auto lookup to suggest hymn title, key, tempo, themes, and public-domain lyrics. Review suggestions before applying them.

Settings

Settings are grouped by accounts, playback defaults, library management, network/system, appearance, and logs. The built-in administrator creates users and grants only the service and audio permissions each person needs.

Network Info

In Network & System, use DHCP by default or save static network details. The DNS name updates the Raspberry Pi hostname on Linux.

Backups

Use Download Complete Backup before major changes and configure an off-device backup path for a USB drive or trusted network share. Complete backups include data, plans, settings, branding, and MP3 files.

Account Recovery

During first-time setup, save the unique administrator recovery code somewhere separate from the Raspberry Pi. Use Recover Administrator on the sign-in screen if the password is lost.

Before Worship

Refresh System Check, confirm the audio output and queue health, test Sound System or AirPlay, load the service plan, select the first hymn, then Lock Service if desired.
