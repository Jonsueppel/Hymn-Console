# Screenshots

Place public-safe screenshots here for the GitHub README.

Recommended screenshots:

- `service-desktop.png`
- `service-mobile.png`
- `library.png`
- `settings.png`
- `login.png`
- `operator-mode.png`

Before committing screenshots, make sure they do not show:

- Passwords
- Recovery codes
- OpenAI keys
- RustDesk passwords
- Private IP addresses if you do not want them public
- Licensed hymn lyrics or copyrighted MP3 information you do not have permission to publish
